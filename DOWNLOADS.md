# Downloads

> **Current release:** `0.1.0-alpha`

Official Standard binaries are published by **Wildclaw Interactive** through this repository's Releases page.

## Standard Studio

```text
Standard-Studio-0.1.0-alpha-win-x64.zip
```

Includes Standard Studio plus the Standard command-line toolchain.

## Standard SDK

```text
Standard-SDK-0.1.0-alpha-win-x64.zip
```

Includes the Standard CLI/compiler toolchain without Standard Studio.

For prerequisites and setup, see [docs/installation.md](docs/installation.md).

Do not download Standard binaries from unofficial mirrors. The Standard license permits use of the toolchain but restricts redistribution of the official IDE/compiler/SDK packages.
