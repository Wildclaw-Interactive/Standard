# Standard Documentation

> **Current public release:** `0.1.2-alpha`

Welcome to the Standard documentation. These filenames are intentionally stable and do **not** include release numbers, so bookmarks and repository links can continue to work across updates. Each guide states which Standard release it currently describes.

- [Getting Started](getting-started.md) — create and run your first Standard project.
- [Language Reference](language-reference.md) — comments, syntax, expressions, functions, loops, lists, and current compiler behavior.
- [Projects](projects.md) — `.standardproject`, multi-file projects, entry files, and targets.
- [Command Line](cli.md) — `standard new`, `check`, `build`, `run`, `info`, and `version`.
- [Standard UI](standard-ui.md) — `.standardui`, controls, events, and the visual designer.
- [Qwen Agent](qwen-agent.md) — optional local Standard-only coding agent in Standard Studio.
- [Licensing and Distribution](licensing.md) — what you may distribute and how commercial use works.
