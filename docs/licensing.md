## Official packages

```text
Standard-Studio-0.1.0-alpha-win-x64.zip
Standard-SDK-0.1.0-alpha-win-x64.zip
```

- **Standard Studio** includes the IDE and Standard toolchain.
- **Standard SDK** contains the CLI/compiler toolchain without the IDE.

There is currently no separate Standard runtime installer. Finished Standard applications use the runtime/dependencies produced by their own build/publish process.
